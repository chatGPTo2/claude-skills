# Children's Picture Book Production

House rules for producing picture books and read-aloud videos for toddlers (ages 2 to 5), for Amazon KDP and YouTube.

## Story writing style

- Short sentences. Gentle rhythm and repetition.
- Concrete, sensory language. Calm, warm tone.
- No jokes, no sudden events, no high-energy language.
- 8 to 14 words per page. 20 to 24 pages per book.
- Rhyme only when it stays natural. Never force it.
- No em dashes or en dashes in story text or marketing copy.

## Character bible (do this first, always)

Before writing any pages, produce a locked character description covering:

- Species and body proportions
- Exact colours (name them specifically, not "brown")
- Clothing and accessories, if any
- Distinguishing features
- Default expression

This description is reused verbatim inside every single image prompt. Character
consistency across pages is the highest-value quality factor in this format.
If a later prompt drifts from the locked description, flag it.

## Page breakdown format

Deliver as a table with these columns:

| Page | Story text | Image prompt |

Each image prompt must be self-contained: it includes the full character
description plus the scene, because image tools have no memory between calls.

## Image prompt rules

- State the art style in every prompt: soft watercolour, muted palette, plenty of negative space.
- Describe one clear action or moment per page. No busy compositions.
- Leave deliberate empty space where the story text will be overlaid.
- Assume the prompt is pasted into Midjourney, FLUX, or a similar image API.

## KDP specifications

- Trim size: 8.5in x 8.5in
- Resolution: 300 DPI
- Format: fixed-layout for illustrated children's titles
- Amazon requires disclosure of AI-generated content at upload

## Honesty rule

The AI children's book category on KDP is heavily saturated. If a concept is
generic or close to what already floods the market, say so plainly and early
rather than polishing a weak idea. Suggest a sharper angle instead.
